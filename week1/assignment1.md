# Week 1 Assignment 1: BMI Calculator

## Objective
Write a Java program that calculates the Body Mass Index (BMI) based on user input and categorizes the result.

## Requirements
- Use only basic Java concepts: variables, data types, operators, control structures (if-else), input/output.
- Do not use classes or methods other than the main method.
- Use `Scanner` for reading user input from the console.
- Use `System.out` for displaying output.

## Problem Description
Create a program that:
1. Prompts the user to enter their height in meters (as a double).
2. Prompts the user to enter their weight in kilograms (as a double).
3. Calculates the BMI using the formula: `BMI = weight / (height * height)`.
4. Displays the calculated BMI with 2 decimal places.
5. Determines and displays the BMI category based on the following ranges:
   - Underweight: BMI < 18.5
   - Normal weight: 18.5 <= BMI < 25
   - Overweight: 25 <= BMI < 30
   - Obese: BMI >= 30

## Example Output
```
Enter your height in meters: 1.75
Enter your weight in kilograms: 70
Your BMI is: 22.86
Category: Normal weight
```

## File Name
Name your Java file `BMICalculator.java`.
