# Java Assignments Repository
Welcome to the Java Assignments repository! This repo is designed for weekly Java programming assignments to help you build and strengthen your Java skills.

## Instructions

- **Weekly Assignments**: 2 coding assignments per week, each designed to test and build specific Java skills.
- **Skill Levels**: Start as a Novice Coder and progress to Java Master through completed assignments.
- **Points System**:
  - 10 points for each completed assignment.
  - Extra 5 points for the first 5 early submissions per week.
  - Bonus points (up to 5) for code quality, efficiency, and creativity.

## Assignment Guidelines

- **Core Rules**: Solve problems using only the specified Java concepts. No external libraries unless allowed.
- **Creativity Encouraged**: While sticking to basics, feel free to add comments, handle edge cases, or optimize for readability.
- **Testing**: Ensure your code compiles and runs correctly. Test with sample inputs.
- **Collaboration**: Discuss ideas with peers, but submit individual solutions.

## Submission Protocol

1. **Create a Branch**: For each assignment, create a branch named `weekX-assignmentY` (e.g., `week1-assignment1`).
2. **Push Your Code**: Add your Java file(s) in the appropriate week folder (e.g., `week1/BMICalculator.java`).
3. **Commit with Flair**: Use commit messages like "Completed BMI Calculator assignment - ready for review!".
4. **Request Review**: Push the branch and request review from the reviewers.There must be at least 2 approvers before any merge happens in main; otherwise, your points won't be counted for that assignment.
6. **Review & Merge**: After review, iterations, and at least 2 approvals, merge to main. Points awarded after review.

## Weekly Quest Structure

Assignments are organized in folders like `week1/`, `week2/`, etc.

Each week folder contains:
- `assignment1.md`: Details for the first assignment.
- `assignment2.md`: Details for the second assignment.

## Deadlines & Scoring

- **Submission Deadline**: End of each week (Friday 5 PM) unless specified.
- **Scoring Criteria**:
  - Correctness (50%): Does it work as specified?
  - Code Quality (30%): Readability, comments, best practices.
  - Efficiency (20%): Optimal use of resources.
  - Bonus: Up to 5 points for creativity and extras.
