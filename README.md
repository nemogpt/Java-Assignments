# Java Assignments Repository

Welcome to the Java Assignments repository! This repo is designed for weekly Java programming assignments to help you build and strengthen your Java skills.

## Instructions

- **Frequency**: 2 assignments per week will be added to this repository.
- **Focus**: Assignments will cover various aspects of Java, starting from basics and progressing to advanced topics.
- **Requirements**: Solve the problems using the specified Java concepts. Do not use external libraries unless explicitly allowed.
- **Submission**:
  - Fork this repository.
  - Create a new branch for your submission (e.g., `assignment-week1-1`).
  - Add your solution file(s) in the appropriate week folder.
  - Commit your changes with a clear message (e.g., "Solution for Week 1 Assignment 1").
  - Create a pull request to the main repository.
- **Evaluation**: Assignments will be reviewed for correctness, code quality, and adherence to requirements.
- **Deadline**: Submit by the end of the week unless specified otherwise.

## Weekly Structure

Assignments are organized by week in folders like `week1/`, `week2/`, etc.

Each assignment folder contains:
- `assignment1.md`: Problem description for the first assignment.
- `assignment2.md`: Problem description for the second assignment.

Good luck, and happy coding!
